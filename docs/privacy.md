# 쪽문 개인정보 처리 안내

쪽문은 사용자가 선택한 기기의 폴더에 메모, 답장, 책방 이름, 입간판과 되돌리기 기록을 저장합니다. 이 정보는 서버로 전송하지 않습니다. 쪽문은 계정 가입, 광고, 방문 분석을 사용하지 않습니다.

## 폴더 접근

폴더를 선택하면 쪽문이 읽기 및 쓰기 권한을 요청합니다. 하위 폴더의 파일 이름과 상대 경로를 읽어 목록을 만들고, 파일을 선택하면 내용을 읽어 미리보기를 제공합니다. 쪽문이 사용하는 저장 파일은 선택한 폴더의 `jjokmun-vault.json`입니다. 쪽문은 다음 실행 때 다시 연결할 수 있도록 마지막으로 연 폴더의 핸들을 이 기기의 Chrome 프로필에 저장합니다. 암호화된 책방의 잠금 해제 키는 해당 탭의 메모리에만 보관합니다.

## 보관과 삭제

사용자는 앱에서 메모와 답장을 수정하거나 삭제할 수 있습니다. 저장소 전체를 제거하려면 쪽문 탭을 닫고 해당 폴더의 `jjokmun-vault.json`을 삭제하세요. 별도로 내보낸 백업은 보관한 위치에서 관리할 수 있습니다. 이전 버전의 프로필에 남은 쪽문 기록은 저장 폴더로 이전한 후 정리합니다.
