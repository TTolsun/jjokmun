# 쪽문 개인정보 처리 안내

쪽문은 사용자가 선택한 기기의 폴더에 메모, 답장, 책방 이름, 입간판과 되돌리기 기록을 저장합니다. 이 정보는 서버로 전송하지 않습니다. 쪽문은 계정 가입, 광고, 방문 분석을 사용하지 않습니다.

## 폴더 접근

폴더를 선택하면 쪽문이 읽기 및 쓰기 권한을 요청합니다. 일반 저장소에서는 하위 폴더까지 탐색하고 지원하는 Markdown·텍스트·다이어그램 문서의 내용을 읽어 전체 메모와 검색 결과에 표시합니다. Markdown에 연결된 로컬 이미지는 해당 문서를 열 때 선택한 폴더 안에서 읽습니다. Mermaid와 PlantUML 다이어그램은 기기 안에서 그립니다. 편집한 문서는 원래 위치에 저장하고, 새 메모는 선택한 폴더에 Markdown 파일로 만듭니다. 그 밖의 파일은 폴더 파일 목록에서 선택하면 미리보기를 엽니다.

추천글과 답장, 문서의 상대 경로와 내용 해시 등 연결 정보는 `jjokmun-vault.json`에 보관합니다. Chrome 프로필에는 마지막으로 연 폴더와 문서를 다시 찾는 데 쓰는 파일 핸들을 저장합니다. 새 메모는 일반 폴더에 평문으로 저장합니다. 이전 버전의 암호화 저장소는 비밀번호로 열 수 있습니다. 일반 폴더로 복사를 확인하면 대상 폴더에 평문 사본을 씁니다. 잠금 해제 키는 해당 탭의 메모리에만 보관합니다.

## 보관과 삭제

앱에서 문서 메모를 삭제하면 쪽문의 목록과 연결된 답장에서 해당 기록이 사라집니다. 원본 `.md`와 `.txt` 파일은 폴더에 남으므로 원본까지 지우려면 파일 관리자에서 해당 파일을 삭제하세요. 책방 기록과 답장을 모두 제거하려면 쪽문 탭을 닫고 해당 폴더의 `jjokmun-vault.json`을 삭제하세요. 별도로 내보낸 백업은 보관한 위치에서 관리할 수 있습니다. 이전 버전의 프로필에 남은 쪽문 기록은 저장 폴더로 이전한 후 정리합니다.
