# 메모고치

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. `manifest.json`이 들어 있는 확장 폴더를 선택합니다. Git 저장소에서 설치할 때는 `extension` 폴더를 선택합니다.
4. Chrome 도구 모음 오른쪽의 **확장 프로그램** 메뉴에서 **메모고치**를 누르면 전용 탭이 열립니다. 자주 쓰려면 메뉴에서 메모고치를 고정해 두세요. Chrome의 새 탭은 기본 화면으로 열립니다.

업데이트하려면 기존 메모고치 탭을 모두 닫고 사용 중인 확장 카드를 새로고침하세요. 메모고치가 다시 열리면 기존 저장 폴더에 자동으로 연결합니다. 폴더를 묻는 안내가 표시되면 이전에 사용하던 폴더를 선택하세요. 이전 버전에서 Chrome 프로필에만 기록을 저장했다면 메모고치 저장 파일이 없는 폴더를 선택하세요. 기록을 옮긴 뒤 예전 프로필 저장소를 정리합니다.

## 작은 정원

작은 정원 기기를 클릭하거나 초점을 둔 상태에서 Enter를 누르면 기기를 들어 올립니다. 확대된 기기에서 **A**로 메뉴나 항목을 차례로 고르고 **B**로 실행합니다. 화면의 메뉴 아이콘과 항목을 직접 눌러도 됩니다. 정원 화면에서 바로 **B**를 누르면 시계가 열립니다.

어느 화면에서든 **C** 또는 Esc를 누르면 기기를 내려놓습니다. 입력 중이던 메모, 답장이나 원문으로 돌아가며 커서와 선택 범위도 복원됩니다. 키보드에서 A와 B 키를 그대로 사용할 수 있으며, 오른쪽 화살표도 A와 같은 역할을 합니다.

1. 저장 폴더를 연 뒤 **알** 메뉴에서 **알 데려오기**를 고르세요. 알을 데려온 지 2분이 지나면 불 강아지, 물 고양이, 풀 햄스터 중 한 마리가 태어납니다. 세 계열의 확률은 같으며, 알을 데려온 뒤 다시 열어도 부화할 계열은 유지됩니다. 이전 버전에서 키우던 알이나 펫은 보관한 모습에서 이어서 돌볼 수 있습니다.
2. **상태** 메뉴에서 허기, 기분, 기력과 건강을 살피세요. 상태 화면에서 **A**를 누르면 성장 경로가 있는 다음 쪽으로 넘어갑니다. **먹이** 메뉴에서 밥이나 간식을 주고, **조명** 메뉴에서 불을 끄고 재우거나 켜서 깨우세요. 배설물이 쌓이면 **청소** 메뉴를 사용하세요. 밤에 잠든 펫은 아침까지 잡니다.
3. 세 계열 모두 두 번 성장합니다. 각 성장기에서 가장 자주 한 공놀이·탐색·쓰다듬기에 따라 다음 모습이 달라집니다. 동률이면 동률인 갈래 중 하나가 정해지며, 아무 활동도 하지 않으면 세 갈래 모두 같은 확률입니다. 첫 성장에서 놀고 두 번째에 탐색하면, 먼저 탐색하고 나중에 놀았을 때와 다른 모습이 됩니다. 첫 성장 뒤에는 자주 한 행동에 맞춰 다음 모습의 특징이 움직임에 조금씩 나타납니다. **공놀이**를 마치면 자란 모습에 따라 공에 다르게 반응합니다.
4. 정원 기기 아래에서 **성장 도감**을 열면 지금 돌보는 펫의 계열이 먼저 보입니다. 계열을 선택해 단계별로 만난 모습과 성장 경로를 살펴보세요. 새 계열은 처음 부화한 뒤 도감에 나타납니다. 마지막 성장을 마치면 새 알을 데려올 수 있으며, 지금까지 발견한 모습은 도감에 남습니다. 메모를 열고 **펫에게 읽어 주기**를 눌러 함께 읽을 수도 있습니다.

### 부화와 진화 시점

| 성장 | 기준 | 입양 후 경과 시간 |
| --- | --- | --- |
| 부화 | 입양 후 2분 | 2분 |
| 첫 진화 | 부화 후 30분 | 32분 |
| 두 번째 진화 | 첫 진화 후 24시간 | 24시간 32분 |

메모고치를 닫거나 펫을 쉬게 해도 같은 시간표로 자랍니다. 여러 성장기가 지난 뒤 돌아오면 거쳐 간 모습도 도감에 남습니다. 진화 예정 시각부터 한 활동은 새 성장기의 기록이 됩니다.

### 공놀이

**놀이** 메뉴에서 **공놀이**를 고르세요. **B**로 시작한 뒤 **A**로 공을 던질 방향을 고르고 **B**로 던집니다. 화면에 표시된 목표를 보고 방향을 맞추세요. 던진 결과를 확인하고 **B**를 누르면 다음 차례로 넘어갑니다. 세 차례를 마치면 한 번 놀아 준 것으로 기록됩니다. 결과 화면에서 **B**를 누르면 정원으로 돌아갑니다. **C**를 누르면 기기를 내려놓습니다. 공놀이 도중 메모를 써도 현재 차례가 유지됩니다. 끝나기 전에 **C**로 나가면 돌봄 기록은 바뀌지 않습니다.

## 메모장

넓은 화면에서는 메모장이 오른쪽에 넓게 표시되고, 작은 정원이 왼쪽에 놓입니다. 좁은 화면에서는 메모장이 먼저 표시되고, 아래에 정원이 이어집니다. Enter로 메모를 저장하고 Shift+Enter로 줄을 바꿀 수 있습니다. 아래의 **최근 메모**에서 글을 고르면 목록 바로 아래에 본문과 답장이 펼쳐집니다. 같은 글을 한 번 더 누르면 접힙니다. 다시 펼치면 작성 중이던 답장과 원문 편집을 이어갈 수 있습니다. 좁은 화면에서는 **최근 메모** 버튼으로 목록을 접고 펼칠 수 있습니다. **답장 쓰기** 입력란에 글을 적고 Enter를 누르거나 **답장 저장**을 선택하세요.

**메모 검색**을 펼치거나 Ctrl K를 누르면 원문, 답장, 폴더 안의 상대 경로를 검색할 수 있습니다. 검색란에서 ↓를 누르면 첫 결과로 이동하고 Enter를 누르면 첫 결과가 열립니다. 메모 본문 아래와 각 답장에 있는 버튼으로 해당 글을 복사하거나 수정하거나 삭제할 수 있습니다.

## 저장 폴더와 파일

첫 화면이나 설정에서 **저장 폴더 선택**을 누르세요. 선택한 폴더에 `jjokmun-vault.json`이 있으면 그 파일의 메모, 답장, 펫 기록을 불러옵니다. 암호화된 저장소는 비밀번호를 입력하면 열립니다. 메모고치는 마지막으로 선택한 폴더를 기억합니다. 새 탭을 열거나 새로고침하면 그 폴더의 기록이 열립니다. 권한을 다시 허용해야 할 때는 폴더 이름 옆의 **다시 연결**을 누르세요. 저장 파일을 옮겼다면 해당 파일이 있는 폴더를 선택하세요. 일반 폴더의 기록을 다른 폴더에 복사하려면 설정에서 메모고치 저장 파일이 없는 폴더를 고르세요.

평문 저장소에서는 하위 폴더에 있는 Markdown, 텍스트, Mermaid, PlantUML 문서가 **최근 메모**에 표시됩니다. 이름이 같은 파일은 상대 경로로 구분할 수 있습니다. 파일당 4 MiB까지 UTF-8과 BOM이 있는 UTF-16 문서를 지원합니다. **원문 수정**으로 해당 파일을 편집할 수 있고, 저장할 때 원본 인코딩과 BOM, 문서 전체에 쓰인 CRLF 줄바꿈을 유지합니다.

- 메모장과 **폴더 파일** 미리보기에서 `.md`와 `.markdown` 문서를 열면 제목, 목록, 표, 인용문, 코드를 서식에 맞게 표시합니다. 메모고치에서는 줄 첫머리에 `# 111` 또는 `#111`을 쓰면 **111**이 1단계 제목이 됩니다. **원문 보기**를 누르면 작성한 Markdown을 그대로 읽을 수 있습니다.
- Markdown에서 코드 블록 언어로 `mermaid`나 `plantuml`을 지정하면 다이어그램이 그려집니다. `.mmd`, `.mermaid`, `.puml`, `.plantuml` 파일도 바로 열 수 있습니다. 구문 오류가 있거나 다이어그램이 30,000자를 넘으면 코드를 표시합니다. 렌더링은 기기에서 이루어집니다.
- 선택한 폴더 안에서 상대 경로로 참조한 PNG, JPEG, GIF, WebP, BMP, AVIF, ICO 이미지를 표시합니다. 상대 경로로 연결한 문서가 **최근 메모**에 있으면 클릭해서 열 수 있습니다. HTTP 또는 HTTPS 링크는 클릭할 때 새 탭에서 열립니다.
- `.txt` 파일은 줄바꿈을 포함한 원문을 표시합니다.

메모장에서 새 메모를 쓰면 저장 폴더의 최상위에 `.md` 파일이 생깁니다. 답장과 펫 기록은 `jjokmun-vault.json`에 보관합니다. **메모 삭제**를 누르면 전체 메모에서 항목이 사라지고 폴더에는 원본 파일이 남습니다.

외부 편집기에서 저장한 뒤 메모고치 탭으로 돌아오거나 **폴더 문서 새로고침**을 누르세요. 옮긴 파일을 찾으면 이전 답장을 이어서 보여 줍니다. 경로를 자동으로 확인할 수 없으면 이전 메모에서 **옮긴 파일 다시 연결**을 사용하세요. 파일이 없어도 이전 답장을 볼 수 있습니다.

원문을 편집하는 동안 외부에서 같은 파일을 바꾸거나 지우면 저장 전에 현재 파일과 작성본을 함께 보여 줍니다. **작성본을 새 메모로 저장**을 누르면 작성한 내용을 별도 메모로 보관합니다. **파일 내용으로 편집 다시 시작**을 누르면 현재 파일 내용을 편집기에 불러옵니다.

**최근 메모 → 폴더 파일**에서 4 MiB 이하의 Markdown 문서와 다이어그램을 열면 전체 내용을 렌더링합니다. 더 큰 파일이나 기타 텍스트 파일은 지원하는 인코딩이면 앞부분 128 KiB까지 읽을 수 있습니다. **원본 파일 저장**으로 전체 파일을 받을 수 있고, **메모장에서 열기**를 누르면 문서를 편집하거나 답장을 남길 수 있습니다.

## 외부 연결과 기기 저장

메모고치는 오프라인에서 작동합니다. 새 메모는 일반 폴더에 문서로 저장합니다. 이전 버전에서 만든 암호화 저장소는 원래 비밀번호로 열 수 있습니다. 잠금 해제는 현재 탭에만 적용되며 **모든 탭 잠그기**로 다시 잠글 수 있습니다.

### 기존 암호화 저장소를 일반 폴더로 복사하기

1. 기존 폴더를 열고 비밀번호를 입력한 뒤 **일반 폴더로 복사**를 누르세요.
2. 원본과 별도의 빈 폴더를 고르세요. 원본과 대상 이름을 확인한 뒤 **복사하고 열기**를 누르면 그때부터 대상에 평문을 씁니다.
3. 메모고치가 대상의 메모와 답장을 다시 읽어 확인하면 새 폴더가 열립니다. 연결된 파일의 외부 편집본은 원래 폴더에 있고, 메모고치에 저장한 내용은 대상 폴더의 같은 상대 경로에 있습니다. 원래 파일이 없던 메모는 대상에서 번호가 붙은 문서로 찾을 수 있습니다.
4. 오류가 나면 저장 공간이나 폴더 권한을 확인하고 기존 암호화 저장소에서 같은 대상을 다시 선택하세요. 원본 기록이나 대상 파일이 바뀌어 재시도할 수 없다는 안내가 나오면 다른 빈 폴더를 고르세요. 기존 암호화 저장소는 복사 후에도 비밀번호로 다시 열 수 있습니다.

예전에 저장한 4 MiB 초과 메모도 원문과 답장을 모두 복구합니다. 일반 텍스트 파일로 표현할 수 없는 특수 문자 기록은 대상의 메모고치 JSON 파일에 원문 그대로 보관합니다. 새로 쓰거나 수정하는 메모의 한도는 4 MiB입니다.

## 백업과 되돌리기

**설정**을 열면 저장 폴더와 암호화, 백업과 복원, 개발자 정보가 한 번에 표시됩니다.

- **설정 → 백업과 복원 → 암호화 백업 내보내기**에서 백업용 비밀번호를 정합니다. 이 비밀번호는 기기 저장소 비밀번호와 별개입니다.
- **설정 → 백업과 복원 → JSON 가져오기**에서 파일을 고릅니다. 암호화 백업은 해당 파일의 비밀번호를 입력해야 열립니다. 이전 버전의 평문 JSON도 가져올 수 있습니다. 암호화할 기록은 32 MiB(인증 태그 포함), 가져올 백업 파일은 48 MiB까지 지원합니다.
- 가져오기 전에 추가할 메모, 바뀔 원문, 새 답장과 충돌을 확인합니다. 같은 ID의 원문은 백업 쪽 수정 시각이 더 최근일 때 반영하며, 답장은 새 ID만 추가합니다. 그사이 다른 탭에서 기록을 바꾸면 미리보기를 갱신하고 다시 확인을 받습니다. 검증이나 저장에 실패하면 기존 기록을 보존합니다. 현재 펫이 없으면 백업의 펫을 복원합니다. 이미 키우는 펫이 있으면 그 펫을 유지하고 백업에서 새로 발견한 모습만 도감에 추가합니다.
- **최근 가져오기 되돌리기**는 마지막으로 변경 사항을 반영한 가져오기에 적용됩니다. 그 뒤에 작성하거나 수정한 기록은 유지하며, 되돌릴 수 없는 충돌이 있으면 결과에 표시합니다. 변경 사항이 없는 백업을 다시 가져와도 기존 되돌리기 기록은 유지됩니다. 내보낸 백업에는 되돌리기 기록을 포함하지 않습니다.

## 암호화 범위

기존 암호화 저장소와 암호화 백업은 AES-GCM 256비트로 보호합니다. 비밀번호에서 키를 만들 때는 PBKDF2-SHA-256을 600,000회 적용합니다. 비밀번호를 잊으면 해당 암호화 파일이나 저장소를 열 수 없습니다. 이미 만든 평문 백업, 시스템이 보관한 이전 사본, 클립보드에 복사한 텍스트는 별도로 관리하세요.

## 브라우저 검증

Node.js 24와 Chrome for Testing으로 검증할 수 있습니다. Git 저장소의 `tests` 폴더(별도 배포본은 `jjokmun-tests`)에서 `npm install`을 실행하세요. `MEMO_CHROME_PATH`에 Chrome for Testing 실행 파일 경로를 지정하거나 `npx playwright-core install chromium`으로 테스트 브라우저를 설치한 뒤 같은 폴더에서 `npm test`를 실행합니다. 테스트는 별도의 임시 Chrome 프로필과 루프백 서버를 사용합니다.
