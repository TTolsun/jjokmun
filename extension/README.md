# jjokmun

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. `manifest.json`이 들어 있는 확장 폴더를 선택합니다. Git 저장소에서 설치할 때는 `extension` 폴더를 선택합니다.
4. Chrome 도구 모음 오른쪽의 **확장 프로그램** 메뉴에서 **jjokmun**을 누르면 전용 탭이 열립니다. 자주 쓰려면 메뉴에서 jjokmun을 고정해 두세요. Chrome의 새 탭은 기본 화면으로 열립니다.

이전 버전의 프로필 기록을 옮기려면 기존 쪽문 탭을 모두 닫고 확장 카드를 새로고침하세요. 첫 화면에서 저장 파일이 없는 폴더를 선택하면 기록을 옮긴 뒤 예전 프로필 저장소를 정리합니다.

## 메모장

저장 폴더를 열면 메모장이 나옵니다. 한 줄을 적은 뒤 Enter 또는 **저장**을 누르세요. 저장한 글은 바로 아래에 열립니다. **전체 메모**에서 예전 글을 고르고 **답장 쓰기**를 펼치면 답장을 남길 수 있습니다.

**메모 검색**을 펼치거나 Ctrl K를 누르면 원문과 답장을 검색할 수 있습니다. 검색란에서 ↓를 누르면 첫 결과로 이동하고 Enter를 누르면 첫 결과가 열립니다. **메모·답장 관리**를 펼치면 원문과 답장을 복사·수정·삭제할 수 있습니다.

**연두의 편지와 책방 소식**을 펼치면 스케치북을 든 연두를 만납니다. **연두에게 건넬 한 줄**에 새 글을 쓰거나 **써 둔 메모에서 고르기**로 예전 글을 건네세요. 다음 방문에서 연두가 그 글을 다시 꺼냈을 때 건넨 뒷이야기는 원래 메모에 답장으로 남습니다.

## 책방과 단골

**설정 → 책방 이름**에서 간판에 쓸 이름을 입력하고 **이름 저장**을 누르세요. 간판에는 첫 입간판 기록부터 센 영업일과 기기의 현재 시각이 함께 표시됩니다.

읽고 있는 원문 아래의 **매대에 놓기**를 누르세요. **책방 매대**에 그 글이 놓이고 바로 아래에 손님들의 반응이 나타납니다. 창가 단골은 쓴 지 일주일 이상 된 글을, 문가 단골은 오늘 답장이 달린 글을 찾아옵니다. 진열한 글을 눌러 다시 열고 답장을 남길 수도 있습니다. 오래된 글에 오늘 답장을 달면 두 단골이 함께 읽습니다.

매대에는 한 편만 놓을 수 있습니다. 다른 메모를 열면 지금 매대에 놓인 글이 표시됩니다. **이 글로 교체하기**를 누르면 매대의 추천글이 바뀌고 이전 글도 메모장에 남습니다. **책방 운영**에서도 추천글 옆의 **손님 반응 보기**를 눌러 매대로 돌아올 수 있습니다.

## 첫 영업과 가구 배치

상단의 **책방 운영**을 열면 첫 영업이 시작되고 마감 뒤에는 다음 날이 자동으로 이어집니다. 손님 열 명이 차례로 들어옵니다. 원하는 책이 있는 손님은 해당 서가로 가고, 둘러보는 손님은 신간 매대 가까이를 지나면 멈춰 책을 펼칩니다. 줄이 길어지면 책을 놓고 돌아가는 손님도 있습니다.

문학 서가, 여행 서가, 신간 매대, 계산대, 열람 테이블, 의자를 마우스나 손가락으로 잡아 바닥에 놓으세요. Tab으로 가구를 고른 뒤 방향키를 눌러 조금씩 옮길 수도 있습니다. 영업 중에도 손님은 달라진 길을 따라갑니다. 매일 같은 손님과 재고로 문을 열며, 서로 다른 날 두 번 이상 책을 사 간 손님은 단골이 됩니다. 마감 때 바닥에 남은 붉은 표시는 기다리던 손님이 책을 내려놓은 자리입니다.

## 단골과 쌓는 정

창가와 문가에서 추천을 기다리는 두 단골 외에도 메모마다 한 명씩 책방을 찾는 단골이 있습니다. 이 손님들은 옷차림에 따라 "안경 쓴 하늘색 카디건 손님"처럼 이름이 붙습니다. **답장 쓰기**를 펼치면 입력란 위에 그 메모의 단골 카드가 표시되고, 다음 단계까지 남은 정과 정을 쌓는 방법을 알려 줍니다.

- 답장을 남긴 날마다 정이 쌓입니다. 하루에 답장을 여러 개 써도 그날의 정은 한 번만 계산합니다.
- 메모를 쓴 날에 답장하면 정 +1, 다른 날 다시 읽고 답장하면 정 +2입니다.
- 오늘의 입간판에 걸린 날 그 메모에 답장하면 정 +3을 줍니다. 입간판을 접은 날은 일반 답장으로 계산합니다.
- 정에 따라 새 단골(0), 낯익은 단골(2), 반가운 단골(5), 오랜 단골(9), 책방 친구(14)로 사이가 깊어집니다. 반가운 단골 이상은 책방에서 책을 고를 때 머리 위에 하트가 뜹니다.

**책방 소식**의 **단골 명부**에는 정이 많은 단골 다섯 명과 단계별 인원이 표시됩니다. 이름을 누르면 해당 메모가 열립니다. 정은 메모, 답장, 입간판 기록에서 매번 계산하므로 저장 파일에 따로 기록하지 않습니다. 답장을 지우면 그만큼 정도 줄어듭니다.

## 이달의 목표와 책방 등급

**책방 소식**의 **이달의 목표**에는 이번 달의 목표 세 가지와 진행 상황이 표시됩니다. 모든 목표는 횟수가 아니라 날짜 수로 셉니다.

- 메모를 쓴 날 8일
- 메모를 쓴 날이 아닌 다른 날 다시 읽고 답장한 날 4일 (입간판 부탁에 답한 날도 포함합니다)
- 입간판에 걸린 날 그 메모에 답장한 날 2일 (입간판을 접은 날은 제외합니다)

탭을 열어 둔 동안 목표를 달성하면 목표 아래에 알림이 표시됩니다. 세 목표를 모두 이룬 달이 1번이면 **이름난 책방**, 3번이면 **골목 명소**로 책방 등급이 오르고, 등급이 오를 때마다 책방에 서가가 하나씩 늘어납니다. 책방 간판 색과 계절 진열대 이름은 계절마다 바뀝니다.

12월 1일부터 다음 해 1월 15일까지는 그해의 **책방 결산**이 표시됩니다. 결산에는 새로 쓴 메모 수, 메모를 쓴 날, 다시 읽고 답장한 날, 들어준 입간판 부탁, 목표를 모두 이룬 달, 가장 부지런했던 달, 올해의 단골이 나옵니다. 목표, 등급, 결산 역시 기록에서 계산하므로 저장 파일에 따로 기록하지 않습니다.

## 저장 폴더와 파일

첫 화면이나 설정에서 **저장 폴더 선택**을 누르세요. 선택한 폴더에 `jjokmun-vault.json`이 있으면 그 파일의 메모, 답장, 책방 이름을 그대로 불러옵니다. 암호화된 책방은 비밀번호를 입력하면 열립니다. 쪽문은 마지막으로 선택한 폴더를 기억합니다. 새 탭을 열거나 새로고침하면 그 폴더의 책방이 열립니다. 권한을 다시 허용해야 할 때는 폴더 이름 옆의 **다시 연결**을 누르세요. 저장 파일을 옮겼다면 해당 파일이 있는 폴더를 선택하세요. 현재 책방을 다른 폴더에 복사하려면 설정에서 쪽문 저장 파일이 없는 폴더를 고르세요.

**전체 메모 → 폴더 파일**에는 하위 폴더까지 모든 확장자의 파일이 상대 경로로 표시됩니다. 경로를 검색하거나 **새로고침**으로 외부 변경 사항을 반영하세요. 텍스트는 앞부분 128 KiB까지 읽을 수 있고 **원본 파일 저장**으로 바이너리를 포함한 전체 파일을 받을 수 있습니다. 폴더 파일은 원래 위치에 있으며 쪽문 메모 수와 단골 수에 포함되지 않습니다.

## 외부 연결과 기기 저장

확장 페이지와 서비스 워커는 오프라인에서 작동합니다. 저장소 암호화는 쪽문 저장 파일에 적용됩니다. 선택한 폴더에 원래 있던 파일은 각 파일의 기존 형식을 유지합니다.

처음에는 기기에 평문으로 저장합니다. **설정 → 저장 폴더와 암호화 → 저장소 암호화**에서 비밀번호를 정하면 기존 기록을 포함해 저장소를 암호화합니다. 열린 탭을 모두 잠그려면 **모든 탭 잠그기**를 누르세요. 암호화한 저장소를 새 탭에서 열거나 Chrome을 재시작하면 비밀번호가 필요합니다. 잠금 해제는 비밀번호를 입력한 탭에만 적용됩니다. **저장소 암호화 해제**를 선택하면 비밀번호 확인 후 이 기기의 기록을 다시 평문으로 저장합니다.

## 백업과 되돌리기

- **설정 → 백업과 복원 → 암호화 백업 내보내기**에서 백업용 비밀번호를 정합니다. 이 비밀번호는 기기 저장소 비밀번호와 별개입니다.
- **설정 → 백업과 복원 → JSON 가져오기**에서 파일을 고릅니다. 암호화 백업은 해당 파일의 비밀번호를 입력해야 열립니다. 이전 버전의 평문 JSON도 가져올 수 있습니다. 파일은 8 MiB까지 지원합니다.
- 가져오기 전에 추가할 메모, 바뀔 원문, 새 답장과 충돌을 확인합니다. 같은 ID의 원문은 백업 쪽 수정 시각이 더 최근일 때 반영하며, 답장은 새 ID만 추가합니다. 그사이 다른 탭에서 기록을 바꾸면 미리보기를 갱신하고 다시 확인을 받습니다. 검증이나 저장에 실패하면 기존 기록을 보존합니다.
- **최근 가져오기 되돌리기**는 마지막으로 변경 사항을 반영한 가져오기에 적용됩니다. 그 뒤에 작성하거나 수정한 기록은 유지하며, 되돌릴 수 없는 충돌이 있으면 결과에 표시합니다. 변경 사항이 없는 백업을 다시 가져와도 기존 되돌리기 기록은 유지됩니다. 내보낸 백업에는 되돌리기 기록을 포함하지 않습니다.

## 암호화 범위

저장소 암호화를 켜면 기기의 메모와 되돌리기 기록을 AES-GCM 256비트로 암호화합니다. 새 백업은 이 설정과 관계없이 같은 방식으로 암호화합니다. 비밀번호에서 키를 만들 때는 PBKDF2-SHA-256을 600,000회 적용합니다. 비밀번호를 잊으면 해당 암호화 파일이나 저장소를 열 수 없습니다. 이미 만든 평문 백업, 시스템이 보관한 이전 사본, 클립보드에 복사한 텍스트는 별도로 관리하세요.

## 브라우저 검증

Node.js 24와 Chrome for Testing으로 검증할 수 있습니다. Git 저장소의 `tests` 폴더(별도 배포본은 `jjokmun-tests`)에서 `npm install`을 실행하세요. `MEMO_CHROME_PATH`에 Chrome for Testing 실행 파일 경로를 지정하거나 `npx playwright-core install chromium`으로 테스트 브라우저를 설치한 뒤 같은 폴더에서 `npm test`를 실행합니다. 테스트는 별도의 임시 Chrome 프로필과 루프백 서버를 사용합니다.

## 시스템 시계를 바꾸지 않고 날짜 확인하기

1. 테스트 기록을 따로 보관하려면 테스트 전용 저장 폴더를 선택합니다.
2. `chrome://extensions`에서 확장 프로그램 ID를 복사합니다. 주소창에 `chrome-extension://확장ID/index.html?date=2026-01-01`을 입력하고 메모를 하나 씁니다. 같은 방식으로 `2026-01-02`, `2026-01-03`에도 메모를 하나씩 씁니다.
3. `date=2026-01-04` 주소를 탭 두 개에서 열어 두 탭 모두 세 번째 메모가 표시되는지 확인합니다. 첫 번째 메모는 1월 2일에, 두 번째 메모는 1월 3일에 이미 입간판에 표시됩니다. 이어서 `2026-01-05`에 열면 첫 번째 메모가, `2026-01-06`에 열면 두 번째 메모가 다시 나옵니다.

주소에 지정한 날짜는 그 탭에서만 적용되며, 테스트 중 남긴 메모와 입간판 기록은 선택한 폴더에 저장됩니다.
