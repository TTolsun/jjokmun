# jjokmun

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
3. `manifest.json`이 들어 있는 확장 폴더를 선택합니다. Git 저장소에서 설치할 때는 `extension` 폴더를 선택합니다.
4. Chrome 도구 모음 오른쪽의 **확장 프로그램** 메뉴에서 **jjokmun**을 누르면 전용 탭이 열립니다. 자주 쓰려면 메뉴에서 jjokmun을 고정해 두세요. Chrome의 새 탭은 기본 화면으로 열립니다.

이전 버전의 프로필 기록을 옮기려면 기존 쪽문 탭을 모두 닫고 확장 카드를 새로고침하세요. 첫 화면에서 저장 파일이 없는 폴더를 선택하면 기록을 옮긴 뒤 예전 프로필 저장소를 정리합니다.

## 한 줄이 책이 되는 책방

쪽문은 책방 화면 하나에서 돌아갑니다. 메모는 책이 되고, 손님은 그 책을 읽고 사 가며, 답장은 그 책을 다시 읽은 기록이 됩니다.

1. 책방 화면 위쪽 입력란에 한 줄을 적고 Enter 또는 **책 꽂기**를 누르세요. 그 메모가 새 책이 되어 신간 매대에 꽂힙니다.
2. 다음에 책을 펼치는 손님이 그 책을 읽습니다. 최근 일주일 안에 쓴 메모는 신간 매대에, 그보다 오래된 메모는 서가에 놓이며, 한쪽이 비어 있으면 다른 쪽 책을 고릅니다.
3. 손님이 책을 사 가면 오른쪽 **팔린 책**에 그 메모가 표시됩니다. 팔린 책을 누르면 메모장에서 그 메모가 열리고 답장 입력란이 바로 준비됩니다.

## 다시 찾는 책

며칠 지난 메모 한 편을 단골이 다시 찾아옵니다. 그날 서가를 찾는 첫 손님이 그 책을 펼치며, 책방 화면의 **다시 찾는 책**에 표시됩니다. 눌러서 답장하면 정 +3을 받습니다. **오늘은 접어두기**를 누르면 그날은 찾지 않습니다.

## 단골과 쌓는 정

메모마다 그 책을 아끼는 단골이 한 명씩 있습니다. 단골은 옷차림에 따라 "안경 쓴 하늘색 카디건 손님"처럼 이름이 붙습니다.

- 답장을 남긴 날마다 정이 쌓입니다. 하루에 답장을 여러 개 써도 그날의 정은 한 번만 계산합니다.
- 메모를 쓴 날에 답장하면 정 +1, 다른 날 다시 읽고 답장하면 정 +2, 단골이 다시 찾는 날 답장하면 정 +3입니다.
- 정에 따라 새 단골(0), 낯익은 단골(2), 반가운 단골(5), 오랜 단골(9), 책방 친구(14)로 사이가 깊어집니다. 반가운 단골 이상인 책을 손님이 읽거나 들고 가면 머리 위에 하트가 뜹니다.

책방 화면의 **단골 명부**에는 정이 많은 단골 다섯 명과 단계별 인원이 표시됩니다. 이름을 누르면 그 메모가 답장 입력란과 함께 열립니다. 정은 메모, 답장, 다시 찾는 책 기록에서 매번 계산하므로 저장 파일에 따로 기록하지 않습니다.

## 연두와 주인의 추천글

책방 화면 아래쪽에는 스케치북을 든 연두가 들릅니다. **연두에게 건넬 한 줄**에 새 글을 쓰거나 **써 둔 메모에서 고르기**로 예전 글을 건네세요. 다음 방문에서 연두가 그 글을 다시 꺼냈을 때 건넨 뒷이야기는 원래 메모에 답장으로 남습니다.

메모장에서 메모를 열고 원문 아래의 **매대에 놓기**를 누르면 그 글이 책방 화면에 **주인의 추천글**로 걸립니다. 추천글은 한 편만 걸 수 있습니다. 다른 메모를 열면 지금 걸린 글이 함께 표시되고, **이 글로 교체하기**를 누르면 추천글이 바뀝니다. 걸린 글에서는 **책방에서 보기**를 눌러 책방으로 돌아갑니다.

## 이달의 목표와 책방 등급

책방 화면의 **이달의 목표**에는 이번 달의 목표 세 가지와 진행 상황이 표시됩니다. 모든 목표는 횟수가 아니라 날짜 수로 셉니다.

- 메모를 쓴 날 8일
- 메모를 쓴 날이 아닌 다른 날 다시 읽고 답장한 날 4일 (다시 찾는 책에 답한 날도 포함합니다)
- 다시 찾는 책에 그날 답장한 날 2일 (접어둔 날은 제외합니다)

탭을 열어 둔 동안 목표를 달성하면 목표 아래에 알림이 표시됩니다. 세 목표를 모두 이룬 달이 1번이면 **이름난 책방**, 3번이면 **골목 명소**로 책방 등급이 오릅니다. 장부 위쪽 선의 색은 계절마다 바뀝니다.

12월 1일부터 다음 해 1월 15일까지는 그해의 **책방 결산**이 표시됩니다. 목표, 등급, 결산 역시 기록에서 계산하므로 저장 파일에 따로 기록하지 않습니다.

## 가구 배치

문학 서가, 여행 서가, 신간 매대, 계산대, 열람 테이블, 의자를 마우스나 손가락으로 잡아 바닥에 놓으세요. Tab으로 가구를 고른 뒤 방향키를 눌러 조금씩 옮길 수도 있습니다. 영업은 짧게 반복되며, 영업 중에도 손님은 달라진 길을 따라갑니다. 줄이 길어지면 책을 놓고 돌아가는 손님도 있고, 마감 때 바닥에 남은 붉은 표시는 그 자리를 나타냅니다.

## 메모장

상단의 **메모장**에서는 쓰고 읽는 일만 합니다. 한 줄을 적은 뒤 Enter 또는 **저장**을 누르면 책방에 새 책이 꽂힙니다. 넓은 화면에서는 왼쪽의 **전체 메모**에서 읽을 글을 고르세요. 좁은 화면에서는 **전체 메모** 버튼으로 목록을 펼칠 수 있습니다. 글을 고르면 목록이 접히고 본문으로 이동합니다. **답장 쓰기** 입력란에 글을 적고 Enter를 누르거나 **답장 저장**을 선택하세요.

**메모 검색**을 펼치거나 Ctrl K를 누르면 원문, 답장, 폴더 안의 상대 경로를 검색할 수 있습니다. 검색란에서 ↓를 누르면 첫 결과로 이동하고 Enter를 누르면 첫 결과가 열립니다. 메모 본문 아래와 각 답장에 있는 버튼으로 해당 글을 복사하거나 수정하거나 삭제할 수 있습니다. 책방 이름은 **설정 → 책방 이름**에서 바꿉니다.

## 저장 폴더와 파일

첫 화면이나 설정에서 **저장 폴더 선택**을 누르세요. 선택한 폴더에 `jjokmun-vault.json`이 있으면 그 파일의 메모, 답장, 책방 이름을 그대로 불러옵니다. 암호화된 책방은 비밀번호를 입력하면 열립니다. 쪽문은 마지막으로 선택한 폴더를 기억합니다. 새 탭을 열거나 새로고침하면 그 폴더의 책방이 열립니다. 권한을 다시 허용해야 할 때는 폴더 이름 옆의 **다시 연결**을 누르세요. 저장 파일을 옮겼다면 해당 파일이 있는 폴더를 선택하세요. 현재 책방을 다른 폴더에 복사하려면 설정에서 쪽문 저장 파일이 없는 폴더를 고르세요.

평문 저장소에서는 하위 폴더에 있는 Markdown, 텍스트, Mermaid, PlantUML 문서가 **전체 메모**에 표시됩니다. 이름이 같은 파일은 상대 경로로 구분할 수 있습니다. 파일당 4 MiB까지 UTF-8과 BOM이 있는 UTF-16 문서를 지원합니다. **원문 수정**으로 해당 파일을 편집할 수 있고, 저장할 때 원본 인코딩과 BOM, 문서 전체에 쓰인 CRLF 줄바꿈을 유지합니다.

- 메모장과 **폴더 파일** 미리보기에서 `.md`와 `.markdown` 문서를 열면 제목, 목록, 표, 인용문, 코드를 서식에 맞게 표시합니다. 쪽문에서는 줄 첫머리에 `# 111` 또는 `#111`을 쓰면 **111**이 1단계 제목이 됩니다. **원문 보기**를 누르면 작성한 Markdown을 그대로 읽을 수 있습니다.
- Markdown에서 코드 블록 언어로 `mermaid`나 `plantuml`을 지정하면 다이어그램이 그려집니다. `.mmd`, `.mermaid`, `.puml`, `.plantuml` 파일도 바로 열 수 있습니다. 구문 오류가 있거나 다이어그램이 30,000자를 넘으면 코드를 표시합니다. 렌더링은 기기에서 이루어집니다.
- 선택한 폴더 안에서 상대 경로로 참조한 PNG, JPEG, GIF, WebP, BMP, AVIF, ICO 이미지를 표시합니다. 상대 경로로 연결한 문서가 **전체 메모**에 있으면 클릭해서 열 수 있습니다. HTTP 또는 HTTPS 링크는 클릭할 때 새 탭에서 열립니다.
- `.txt` 파일은 줄바꿈을 포함한 원문을 표시합니다.

메모장이나 책방에서 새 메모를 쓰면 저장 폴더의 최상위에 `.md` 파일이 생깁니다. 답장과 책방 기록은 `jjokmun-vault.json`에 보관합니다. **메모 삭제**를 누르면 전체 메모에서 항목이 사라지고 폴더에는 원본 파일이 남습니다.

외부 편집기에서 저장한 뒤 쪽문 탭으로 돌아오거나 **폴더 문서 새로고침**을 누르세요. 옮긴 파일을 찾으면 이전 답장과 책방 기록을 이어서 보여 줍니다. 경로를 자동으로 확인할 수 없으면 이전 메모에서 **옮긴 파일 다시 연결**을 사용하세요. 파일이 없어도 이전 답장과 책방 기록을 볼 수 있습니다.

원문을 편집하는 동안 외부에서 같은 파일을 바꾸거나 지우면 저장 전에 현재 파일과 작성본을 함께 보여 줍니다. **작성본을 새 메모로 저장**을 누르면 작성한 내용을 별도 메모로 보관합니다. **파일 내용으로 편집 다시 시작**을 누르면 현재 파일 내용을 편집기에 불러옵니다.

**전체 메모 → 폴더 파일**에서 4 MiB 이하의 Markdown 문서와 다이어그램을 열면 전체 내용을 렌더링합니다. 더 큰 파일이나 기타 텍스트 파일은 지원하는 인코딩이면 앞부분 128 KiB까지 읽을 수 있습니다. **원본 파일 저장**으로 전체 파일을 받을 수 있고, **메모장에서 열기**를 누르면 문서를 편집하거나 답장을 남길 수 있습니다.

## 외부 연결과 기기 저장

확장 페이지와 서비스 워커는 오프라인에서 작동합니다. 저장소 암호화를 켜면 쪽문은 읽어 둔 메모를 `jjokmun-vault.json`에 암호화해 보관합니다. 폴더에 남은 `.md`와 `.txt` 원본은 다른 앱에서 평문으로 열 수 있습니다. 암호화 중에 쪽문에서 작성하거나 수정한 내용은 암호화 저장 파일에 기록됩니다.

처음에는 기기에 평문으로 저장합니다. **설정 → 저장 폴더와 암호화 → 저장소 암호화**에서 비밀번호를 정하면 기존 기록을 포함해 저장소를 암호화합니다. 열린 탭을 모두 잠그려면 **모든 탭 잠그기**를 누르세요. 암호화한 저장소를 새 탭에서 열거나 Chrome을 재시작하면 비밀번호가 필요합니다. 잠금 해제는 비밀번호를 입력한 탭에만 적용됩니다. **저장소 암호화 해제**를 선택하면 비밀번호 확인 후 이 기기의 기록을 다시 평문으로 저장합니다.

## 백업과 되돌리기

- **설정 → 백업과 복원 → 암호화 백업 내보내기**에서 백업용 비밀번호를 정합니다. 이 비밀번호는 기기 저장소 비밀번호와 별개입니다.
- **설정 → 백업과 복원 → JSON 가져오기**에서 파일을 고릅니다. 암호화 백업은 해당 파일의 비밀번호를 입력해야 열립니다. 이전 버전의 평문 JSON도 가져올 수 있습니다. 파일은 8 MiB까지 지원합니다.
- 가져오기 전에 추가할 메모, 바뀔 원문, 새 답장과 충돌을 확인합니다. 같은 ID의 원문은 백업 쪽 수정 시각이 더 최근일 때 반영하며, 답장은 새 ID만 추가합니다. 그사이 다른 탭에서 기록을 바꾸면 미리보기를 갱신하고 다시 확인을 받습니다. 검증이나 저장에 실패하면 기존 기록을 보존합니다.
- **최근 가져오기 되돌리기**는 마지막으로 변경 사항을 반영한 가져오기에 적용됩니다. 그 뒤에 작성하거나 수정한 기록은 유지하며, 되돌릴 수 없는 충돌이 있으면 결과에 표시합니다. 변경 사항이 없는 백업을 다시 가져와도 기존 되돌리기 기록은 유지됩니다. 내보낸 백업에는 되돌리기 기록을 포함하지 않습니다.

## 암호화 범위

저장소 암호화를 켜면 기기의 메모와 되돌리기 기록을 AES-GCM 256비트로 암호화합니다. 새 백업은 이 설정과 관계없이 같은 방식으로 암호화합니다. 비밀번호에서 키를 만들 때는 PBKDF2-SHA-256을 600,000회 적용합니다. 비밀번호를 잊으면 해당 암호화 파일이나 저장소를 열 수 없습니다. 이미 만든 평문 백업, 시스템이 보관한 이전 사본, 클립보드에 복사한 텍스트는 별도로 관리하세요.

## 브라우저 검증

Node.js 24와 Chrome for Testing으로 검증할 수 있습니다. Git 저장소의 `tests` 폴더(별도 배포본은 `jjokmun-tests`)에서 `npm install`을 실행하세요. `MEMO_CHROME_PATH`에 Chrome for Testing 실행 파일 경로를 지정하거나 `npx playwright-core install chromium`으로 테스트 브라우저를 설치한 뒤 같은 폴더에서 `npm test`를 실행합니다. 테스트는 별도의 임시 Chrome 프로필과 루프백 서버를 사용합니다.

## 시스템 시계를 바꾸지 않고 날짜 확인하기

1. 테스트 기록을 따로 보관하려면 테스트 전용 저장 폴더를 선택합니다.
2. `chrome://extensions`에서 확장 프로그램 ID를 복사합니다. 주소창에 `chrome-extension://확장ID/index.html?date=2026-01-01`을 입력하고 메모를 하나 씁니다. 같은 방식으로 `2026-01-02`, `2026-01-03`에도 메모를 하나씩 씁니다.
3. `date=2026-01-04` 주소를 탭 두 개에서 열어 두 탭 모두 세 번째 메모가 표시되는지 확인합니다. 첫 번째 메모는 1월 2일에, 두 번째 메모는 1월 3일에 이미 입간판에 표시됩니다. 이어서 `2026-01-05`에 열면 첫 번째 메모가, `2026-01-06`에 열면 두 번째 메모가 다시 나옵니다.

주소에 지정한 날짜는 그 탭에서만 적용되며, 테스트 중 남긴 메모와 입간판 기록은 선택한 폴더에 저장됩니다.
